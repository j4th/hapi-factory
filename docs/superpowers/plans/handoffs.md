The subagent-driven-development (SDD) ledger under `.superpowers/sdd/` is scratch: it is gitignored and deleted when a plan finishes, so nothing may live only there.
Rules: every deferral lands here in the same commit that defers it; each task or plan starts by pulling its section into its own steps; closing an item moves it to [Closed](#closed) with the commit that closed it. IDs are never reused.
Plan: [Plan 01, Foundations](2026-10-26-hapi-factory-01-foundations.md) (Tasks 1–7, 3b, 4b, 4c, 7b, spikes 8–14), then Plans 02–07 and Phases 2–5.
Snapshot: built from Plan 01's ledger, task reports and review outputs, and checked against committed HEAD `2ea2145` on 2026-10-26. From here on, each deferral is added by the commit that defers it.

**Sources.** `ledger L<n>` is line n of Plan 01's SDD ledger (`progress.md`). `T<n> brief am.<k>` is controller amendment k in task n's brief. `T<n> report` is task n's implementer report. `T<n> review` and `T<n> fix review` are the review outputs of that task's workflow runs (T1 wbhxevp9c; T2 w6hmq9d68, fix pass wie5pfbpz; T3 whqfw7hso, fix pass wtglrdx97; T3b wu4t21iky, fix pass wg06ewemv; T4 wno79cf0l; T4b wreoafj4i; T4c wyk6wr87l). `HEAD <path>` is the committed file at `07f8583`.
